# 唤醒闪烁 · 顶部特效

## ① 唤醒后闪一下

**原因**：`showPanel()` 每次都先 `setOpacity(0)` 再 `show()` 再 60ms 后 `setOpacity(1)`。
第一次显示没问题，但**唤醒时面板往往已经开着**，这一套就把可见窗口瞬间变成全透明再拉回来——肉眼就是闪一下。

**改法**：只有「从未显示 → 显示」时才做淡入，已经可见就只对齐位置。

```ts
const already = panel.isVisible()
panel.setBounds(...)
if (!already) { setOpacity(0); show(); setTimeout(() => setOpacity(1), 50) }
```

**验证**（日志里两次连续 showPanel）：

```
showPanel x=1492 y=278 already=false   ← 首次：淡入
showPanel x=1492 y=278 already=true    ← 第二次：不碰 opacity
```

## ② 屏幕顶部流动特效

新增一个独立窗口 `overlay`：铺满全屏、`alwaysOnTop('screen-saver')`、`focusable: false`、
**永久 `setIgnoreMouseEvents(true)`**——它只负责画画，绝不吃鼠标、不抢焦点。

渲染层是一块 canvas，画四条正弦缎带 + 顶部亮线 + 横扫光斑，纯 `requestAnimationFrame`，透明度与配色都做缓动：

| 状态 | 颜色 | 触发 |
|---|---|---|
| 冷色（青 → 蓝 → 紫） | `#6fe3ff` `#7ea8ff` `#b18cff` | 听到你 / 在想 / 在说 / 等确认 |
| 暖色（琥珀 → 橙 → 红） | `#ffd479` `#ff9a4d` `#ff5d73` | **正在调用工具操作电脑** |

节奏也跟状态走：`listening 0.55` / `thinking 1.35` / `speaking 1.0` / `action 1.6`（数字是流速倍率）。

### 状态从哪来

- 语音侧：`butler.broadcast()` 里同步 `overlaySetState(state)`。
- 工具侧：所有工具都过 `executeToolCall()`，在那里 `overlayToolStart()` / `finally overlayToolEnd()`。
  所以不管是从对话调工具、还是语音直接动手，只要动电脑就是暖色。
- 两者同时存在时**工具优先**（`toolDepth > 0` 就画暖色）。

### 验证

截屏（真屏幕，非合成）：

- 说话时：`docs/overlay-top.png` — 顶部蓝紫色流动缎带
- 工具执行时：`docs/overlay-action.png` — 同一位置变成琥珀橙色

调试可跑：`BUTLER_OVERLAY_DEMO=1`（点亮暖色 9 秒，不动鼠标、不发声音）。

## 不抢鼠标的保证

源码与构建产物里，`setIgnoreMouseEvents` 只有两处：

```
ball.setIgnoreMouseEvents(false)                          // 球：永远可点
overlayWin.setIgnoreMouseEvents(true, { forward: false })  // 特效层：永远穿透
```

特效层没有第二处调用，也就是说它不存在「吃掉点击」的代码路径。

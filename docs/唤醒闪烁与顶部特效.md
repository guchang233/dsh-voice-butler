# 唤醒闪烁 · 顶层特效

## ① 唤醒后闪一下

**原因**：`showPanel()` 每次都先 `setOpacity(0)` 再 `show()` 再 60ms 后 `setOpacity(1)`。
第一次显示没问题，但**唤醒时面板往往已经开着**，这一套就把可见窗口瞬间变成全透明再拉回来——肉眼就是闪一下。

**改法**：只有「从未显示 → 显示」时才做淡入，已经可见就只对齐位置。

```ts
const already = panel.isVisible()
panel.setBounds(...)
if (!already) { setOpacity(0); show(); setTimeout(() => setOpacity(1), 50) }
```

## ② 顶层特效（第二版，四色模式）

独立窗口 `overlay`：铺满**整个虚拟桌面**（多屏时取所有屏幕的外接矩形，这样「屏幕的四条边」才成立）、
`alwaysOnTop('screen-saver')`、`focusable: false`、**永久 `setIgnoreMouseEvents(true)`** ——
它只负责画画，绝不吃鼠标、不抢焦点。

### 四档配色

| 模式 | 颜色 | 什么时候 |
|---|---|---|
| `wake` | **绿** `#3AF5A6` | 被叫醒后在听你说（`listening`） |
| `think` | **蓝** `#60ACFF` | 在想 / 在说 / 等确认（`thinking` `speaking` `confirming`） |
| `act` | **橙** `#FFB454` | 正在操作这台电脑：跑命令、改文件、查网页…… |
| `mouse` | **橙，且四边全亮** `#FF8A18` | 已经在**动鼠标 / 敲键盘**操作界面了 |

优先级：`mouse` > `act` > `think` > `wake` > 关。模式切换时颜色做缓动，不硬跳。

### 每一帧叠了什么

从底到顶：

1. **全屏氛围染色**——中间几乎不动，越靠边越浓
2. **四条边的光晕**（wake/think 108–122px，act 146px，mouse 186px）
3. **内嵌边框 + 行军虚线**（虚线偏移随时间跑，频率跟模式走）
4. **霓虹边框**——贴着屏幕四边的实心亮线，带呼吸；内侧再压一条更亮的细线
5. **四角括号**（双层，外层粗、内层像取景框）
6. **四角靶环**——act/mouse 才有，从角落一圈圈扩散
7. **沿边扫动的光带**——wake/think 两条（上下），act/mouse 四条
8. **粒子**——贴边往里飘，闪烁
9. **切换瞬间的冲击波 + 全屏闪**（1.1 秒）
10. **缓慢下移的扫描线**

全部纯 `requestAnimationFrame` + canvas 2D，渐变的透明度每帧只改 alpha，不做大范围模糊。

### 状态从哪来

| 来源 | 怎么进来 |
|---|---|
| 语音状态 | `voice.ts` 的 `setState()` → `overlaySetState(state)` |
| 工具开始/结束 | `voice.ts` 收到 `tool` 帧 → `overlayToolStart(activity)` / `overlayToolEnd(activity)` |

**鼠标操作怎么认出来的**：判断放在桥里（`butler-bridge/lib/index.js` 的 `classifyTool()`），因为那里拿得到
**完整**参数（面板上那条摘要是截断到 140 字的）。命中这些特征就算「在动鼠标」：

```
SetCursorPos / Cursor::Position / [System.Windows.Forms.Cursor] / mouse_event / SendInput
pyautogui / .Click( / SendKeys / nircmd setcursor|click|sendmouse / 移动鼠标 / 点击坐标 / 模拟点击
```

帧里带 `activity: 'tool' | 'mouse'`，`tool/result` 回来时按 `callId → activity` 的记账还原，
所以「结束」也知道该收哪种特效。

两个残留时间：鼠标特效多留 **1.6 秒**、普通工具留 **0.7 秒**——不然快速点一下就闪没了。

## 不抢鼠标的保证

源码与构建产物里，`setIgnoreMouseEvents` 只有两处：

```
ball.setIgnoreMouseEvents(false)                          // 球：永远可点
overlayWin.setIgnoreMouseEvents(true, { forward: false })  // 特效层：永远穿透
```
